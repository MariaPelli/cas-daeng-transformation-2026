# Checkpoints

Nach jedem Workshopblock wird hier ein geprüfter Zwischenstand unter einem
neuen Dateinamen ergänzt. Bestehende Checkpoints werden während des Workshops
nicht überschrieben.

Das geplante Namensschema lautet:

```text
checkpoint_01_profiled.parquet
checkpoint_02_basic_cleaning.parquet
checkpoint_03_near_duplicates.parquet
```

Die endgültigen Namen ergeben sich aus der Blaupause der neun Lektionen.
