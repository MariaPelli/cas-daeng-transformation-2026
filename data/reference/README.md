## NYC TLC Taxi Zone Lookup

`taxi_zone_lookup.csv` ordnet den in den Fahrtdaten enthaltenen `LocationID`
einem Borough, einem Zonennamen und einer Service-Zone zu.

- Offizielle Übersichtsseite: <https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page>
- Direkte CSV-Datei: <https://d37ci6vzurychx.cloudfront.net/misc/taxi_zone_lookup.csv>
- Abgerufen: 3. September 2026
- Zeilen: 265
- SHA-256: `1a99e105092230f8620f301edcca7f80d3080642ff404d28ed957d3fa222c8ed`

Die Datei wird unverändert bereitgestellt. Die TLC weist darauf hin, dass die
zugrunde liegenden Trip Records von Technologieanbietern geliefert werden und
keine Garantie für deren Genauigkeit oder Vollständigkeit besteht.
