Aufgabe 0 enthält vier CSV-Dateien im eigenen Unterordner `data/`. Mit Aufgabe 1 beginnt der Taxifall.

Dateien pro Aufgabe:

```text
README.md
task.ipynb
WALKTHROUGH.md
task_sample_solution.ipynb
```

`task.ipynb` wird im zentralen Repository nach Workshopbeginn nicht mehr
verändert.

Jeder freigegebene Walkthrough enthält ausserdem direkte Links auf die neu
hinzugekommenen Dateien. Dadurch können Teilnehmende ohne Git genau diese
Dateien manuell herunterladen.
